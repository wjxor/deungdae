# route_mode 비교 실험 — 안심경로 방식 결정 근거

실험일: 2026-09-29 · 담당: 고상협 · 관련: FR-006, ROADMAP "안심경로 계산 방식"

```bash
node --env-file=.env scripts/kakao-walk-test.ts --pairs scripts/route-pairs.json
```

## 목적

B안(후보 비교)은 카카오 도보 API의 `route_mode` 3종으로 후보 3개를 만든다. 세 후보가 **실제로 다른 길인지** 확인한다.
거의 같은 길이면 B안만으로는 고를 게 없다.

## 방법

- **귀갓길 10쌍**: 직선거리 0.5km / 1.1~1.4km / 2.1~2.4km, 길 유형(대학가·원도심 골목·신도시 격자), 5개 구를 섞었다. 좌표는 `scripts/route-pairs.json`
- 쌍마다 `SHORTEST`(최단)·`BROAD_FIRST`(넓은 길 우선)·`ACCESSIBLE`(편안한 길)을 호출했다. 총 30건, 전부 HTTP 200·`OK`
- **겹침**: 경로를 5m 간격으로 잘라, 다른 경로에서 **20m 안**이면 같은 길로 셌다. 양방향으로 재서 겹침률은 작은 값, "다른 길" 길이는 큰 값을 썼다
  - 20m 근거: 안전점수 초안이 시설을 반경 30m로 세므로, 20m 안의 두 길은 거의 같은 시설을 센다
- **다른 후보** 판정: 겹침 90% 미만이면 다른 길로 봤다 (이번 해석용 기준)

## 알게 된 것

1. **넓은 길 우선과 편안한 길은 대부분 같다.** 10쌍 중 7쌍에서 겹침 98% 이상이다. 달랐던 3쌍(2·7·10번)은 모두 지하철역 출발이고, 편안한 길이 엘리베이터 출구로 나가면서 갈렸다. 3종을 호출해도 실질 후보는 **최단 vs 넓은 길 우선, 2개**다.
2. **최단과 넓은 길 우선은 10쌍 중 7쌍에서 다른 길이다.** 안내 문구를 보면 최단은 골목·빌라 사이·시설 내부 길(7번: "출입구15", "화장실" 경유)을 지나고, 넓은 길 우선은 대로(한밭대로·대학로·계족산로)를 탄다. 야간 후보로서 의미 있는 차이다. 단, 대로가 실제로 시설 점수가 높은지는 데이터 적재 후 확인해야 한다.
3. **대안이 없는 경우가 3/10이다.** 3번(3종 완전 동일), 6번(다른 길 88m), 2번(최단 = 넓은 길이고, 편안한 길은 출구만 다름)이다. 이 30%는 B안만으로는 고를 게 없다.
4. **우회 비용은 작다.** 넓은 길 우선의 추가 거리는 최대 +11.3%(320m)이고, 10쌍 중 8쌍이 +6% 이하다.
5. **거리가 멀수록 후보가 갈린다.** 2km 이상 3쌍은 모두 다른 길이 1km를 넘는다. 1.5km 이하 7쌍 중 3쌍은 대안이 없다. 다만 둔산처럼 길이가 비슷한 격자 도로가 많은 곳(7번)은 가까워도 크게 갈린다.

### 부수 발견

- 5번(중앙로역 → 대사동성당)은 최단·넓은 길 모두 **"지하보도 이용" 400m** 구간을 지난다. 야간 통행이 가능한지는 확인하지 못했다. 안전점수에 구간 성격을 반영하지 않기로 했지만(ROADMAP "결정된 것"), 안내 문구에 나오므로 필요하면 감지할 수는 있다.

## 한계

- 10쌍은 경향 확인용 표본이고, 통계적 결론이 아니다.
- **겹침이 낮다고 안전점수가 다른 것은 아니다.** 시설 데이터를 적재한 뒤 후보별 안전점수를 다시 비교해야 B안이 실제로 쓸모 있는지 확정된다.
- 20m·90% 기준은 이번 실험용 가정이다 (스크립트 상수 `OVERLAP_TOLERANCE_M`).
- 카카오 경로는 시점에 따라 바뀔 수 있다. 2026-09-29 기준이다.

## 팀 결정에 주는 의미 (제안 — 결정은 팀 회의에서)

- B안 단독: 70%는 후보가 2개 이상이지만 사실상 최단 vs 넓은 길 우선 2개이고, 30%는 대안이 없다.
- **"B 기본 + A 보강"(상협 제안)과 맞는다.** 후보끼리 겹침이 높으면(예: 90% 이상) 경유지 1~2개로 후보를 추가한다.
- 쿼터: 편안한 길이 넓은 길 우선과 대부분 같으므로, 빼면 검색 1회당 도보 API 호출이 3건 → 2건으로 준다(하루 약 330회 → 500회). 단, A 보강 때는 경유지 경로 호출이 더해진다.
