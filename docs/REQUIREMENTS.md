# 등대 — 요구사항 정의

기준: 3주차 진행보고 발표자료 4·5페이지. ID는 절대 다시 매기지 않는다 (다른 문서·커밋이 참조함).

## 기능 요구사항 (FR)

| ID | 분류 | 요구사항 | 중요도 | MoSCoW |
|---|---|---|---|---|
| FR-001 | 지도 | 카카오맵으로 지도를 띄우고, 위치 권한 승인 시 현재 위치 표시 | 상 | Must |
| FR-002 | 안전시설 | CCTV·안심벨·지구대 위치를 아이콘으로 표시 (가로등·보안등은 안전점수에만 사용) | 상 | Must |
| FR-003 | 경로탐색 | 출발지·도착지 입력, 현재 위치를 출발지로 자동 지정 | 상 | Must |
| FR-004 | 경로탐색 | 카카오맵 도보 길찾기로 거리 기준 최단경로 계산 | 상 | Must |
| FR-005 | 경로탐색 | 현재 시각과 일몰시간으로 주간/야간 자동 판별, 수동 전환 가능 | 상 | Must |
| FR-006 | 경로탐색 | 야간에는 구간별 안전점수(시설 밀도)를 반영해 안심경로 계산 — **핵심** | 상 | Must |
| FR-007 | 경로탐색 | 최단경로와 안심경로를 함께 표시하고 거리·소요시간 제공 | 상 | Must |
| FR-008 | 경로탐색 | 구간별 안전점수를 초록·노랑·빨강으로 표시 | 중 | Should |
| FR-009 | 제보 | 위험 위치 선택·사진 첨부, 위치·사진·시각·작성자 저장 | 중 | Could |
| FR-010 | 제보 | 누적 제보가 기준을 넘으면 구간 점수를 낮춰 회피 대상으로 반영 | 중 | Could |
| FR-011 | 회원 | 이메일·소셜 로그인, 제보 이력을 계정과 연결 | 중 | Could |

- FR-002: 3주차 발표자료에는 24시간 시설(편의점·심야 약국)이 있었으나 **제외** (2026-10-10, 승민 제안·상협 동의, PR #6). 편의점은 카카오 카테고리 검색으로만 받을 수 있어 대전 전체를 받으려면 영역을 나눠 여러 번 불러야 하고, 응답에 영업시간이 없어 24시간 운영인지 알 수 없다. 약국도 함께 뺀다. 안전점수 규칙의 24시 시설(+4)도 같이 뺐다
- FR-002: 3주차 발표자료에는 가로등도 아이콘 표시 대상이었으나 **표시하지 않는다** (2026-10-14, 승민 제안·상협 동의, PR #9). 가로등·보안등은 합쳐 7만 개가 넘어 지도에 띄우기 어렵고, 안전점수(FR-006) 계산에는 그대로 쓴다. 대신 지구대·파출소를 표시 대상에 넣었다

## 화면 (와이어프레임 4종)

| 화면 | 내용 | 관련 요구사항 |
|---|---|---|
| S1 지도 홈 | 현재 위치, 주변 안전시설 아이콘(종류별로 켜고 끄기), 상단 도착지 검색, [경로 찾기]·[제보하기] | FR-001·002·003 |
| S2 경로 입력 | S1에서 고른 도착지를 이어받고, 출발지는 위치 권한이 있으면 현재 위치로 자동 입력(검색으로 바꿀 수 있음), 없으면 장소·주소 검색으로 입력. 지도 미리보기 | FR-003·004·006 |
| S3 경로 비교 | 최단경로(점선)와 안심경로를 한 지도에 표시, 소요시간 비교, 구간 색상 — **핵심 화면** | FR-007·008 |
| S4 위험 제보 | 사진 첨부, 현재 위치 또는 지도에서 위치 선택, 유형(조명 부족·CCTV 없음·우범지역) | FR-009 |

- S1·S2: 이전에는 "S1 상단 출발지 검색"이었으나, **S1 검색창은 도착지 검색**으로 하고 출발지는 도착지를 고른 뒤 S2에서 정한다 (2026-10-20 승민 제안·상협 동의, PR #17). 위치 권한을 거부한 사용자(iOS 등)는 S2에서 출발지를 장소·주소로 검색한다 (API.md 2장 `/places`)
- S2: 지도에서 출발지를 직접 고르는 기능은 9주차 MVP 뒤 여유가 있으면 만든다. 방식은 **지도를 눌러 그 자리에 핀을 찍는 것**으로 한다 (2026-10-21 승민, PR #19 댓글). 고른 곳은 주소 대신 "지도에서 고른 위치"로 표시한다 (좌표를 주소로 바꾸는 API는 두지 않음, API.md 2장). S4의 "지도에서 위치 선택"도 같은 방식으로 맞춘다
- S1: 안전시설 아이콘은 종류(CCTV·안심벨·지구대)별로 켜고 끌 수 있다 (2026-10-19 승민, PR #17)

주간·야간 모두 최단경로와 안심경로를 함께 받아 오고, 주야간에 따라 기본으로 보여 줄 경로(추천)만 바뀐다. 주야간 토글은 경로를 다시 부르지 않고 표시만 바꾼다 (API 명세 `POST /routes/search`에 맞춰 2026-10-13 정리. 3주차 자료는 "주간에는 최단경로만, 야간에만 안심경로를 따로 계산").

## 프로젝트 범위

**In-scope (7)**: 최단경로 탐색, 안심경로 탐색, 안전시설 지도 표시, 구간별 안전도 색상, 위험 구간 제보, 공공데이터 수집·정제, 주야간 판별

**Out-of-scope (6)**: 제보 누적 점수 자동 반영, 회원가입·로그인, 허위 제보 방지, 자동차·대중교통 경로, 관리자 페이지, 제보 사진 자체 저장(클라우드 스토리지 URL 참조)

※ 제보·회원·로그인은 Could로 확정(13주차 여유 시). 12페이지의 "In-scope 차별점" 표현은 다음 자료에서 정리 예정.

## 데이터 (DATA 담당)

공공데이터포털 활용 신청은 전부 승인됐고 카카오맵 API 키도 발급됨 (3주차). 6~7주차 데이터 구축을 앞당길 수 있다.

| 데이터 | 출처 | 형식 | 용도 | 상태 |
|---|---|---|---|---|
| 대전광역시 가로등 현황 | 공공데이터포털 (data.go.kr/data/15110054) | CSV, JSON | 안전점수 | 승인 |
| 대전광역시 보안등 조회 | 공공데이터포털 (15110685) | XML, JSON | 안전점수 | 승인 |
| 대전광역시 방범용 CCTV | 공공데이터포털 (15109459) | JSON | 안전점수 | 승인 |
| 행정안전부 안전비상벨 위치정보 | 공공데이터포털 | XML, JSON | 안전점수 | 승인 |
| 경찰청 전국 지구대·파출소 주소 | 공공데이터포털 | CSV, JSON | 안전점수 (주소만 있으면 지오코딩 필요) | 승인 |
| 국립중앙의료원 전국 약국 정보 | 공공데이터포털 (15000576) | XML, XLS | 쓰지 않음 — 24시 시설 제외 (2026-10-10). 원래 용도는 심야 운영 약국 필터 | 승인 |
| 한국천문연구원 출몰시각 정보 | 공공데이터포털 (15012688) | XML | FR-005 주야간 자동 판별 | 승인 |
| 카카오맵 API | developers.kakao.com | REST, JS SDK | 지도, 도보 경로, 장소 검색 | 키 발급 |
| 보행자 도로망 | OpenStreetMap | — | C안 자체 탐색 시 | 미착수 |

- 대전 한정 데이터는 CSV 일괄 다운로드, 전국 단위 데이터는 API 호출에 지역 필터 파라미터가 있는지 확인 후 결정
- 각 데이터에 좌표 컬럼이 있는지 먼저 확인. 없으면 지오코딩(카카오 로컬 API)이 필요하고 작업량이 늘어난다
- 좌표계는 전부 WGS84(EPSG:4326)로 변환해 적재. 결측·대전 밖 행은 제거하고 건수를 기록
- 적재 후 DBeaver에서 건수 확인, QGIS로 지도 위 분포 확인
- 생활안전지도 WMS(범죄주의구간, 여성밤길치안안전)는 이미지 레이어라 점수 계산에는 못 쓴다. 참고용

## 안전점수 규칙 (초안 — 5단계에서 실제 경로 보며 조정)

구간(약 50m 단위)마다 반경 30m 안의 시설을 센다.

| 시설 | 가중치 |
|---|---|
| 가로등 | +1 / 개 |
| CCTV | +3 / 대 |
| 안심벨 | +5 / 개 |
| 제보 (최근 30일) | −5 / 건 |

- 구간 점수를 0~100으로 정규화. 경로 점수는 구간 점수의 거리 가중 평균
- 색상: 70 이상 안전(초록) / 40~69 주의(노랑) / 39 이하 위험(빨강)
- 숫자는 전부 초안이다
